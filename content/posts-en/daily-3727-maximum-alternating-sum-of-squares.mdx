You are given an integer array `nums`. You may **rearrange the elements** in any order.

The **alternating score** of an array `arr` is defined as:

- `score = arr[0]^2 - arr[1]^2 + arr[2]^2 - arr[3]^2 + ...`

Return an integer denoting the **maximum possible alternating score** of `nums` after rearranging its elements.

**Constraints:**

- `1 <= nums.length <= 10^5`
- `4 * 10^4 <= nums[i] <= 4 * 10^4`

## Approach: Greedy

Put the numbers with smaller absolute values in even positions and the larger ones in odd positions. Equivalently, subtract the squares of the smallest `n // 2` values.

```python
class Solution:
    def maxAlternatingSum(self, nums: List[int]) -> int:
        n = len(nums)
        new_nums = sorted(nums, key=lambda x: abs(x))
        return sum([num**2 for num in new_nums[n//2:]])-sum([num**2 for num in new_nums[:n//2]])
```

## Complexity

- Time: O(n log n) — sorting dominates.
- Space: O(n) — the sorted copy.
