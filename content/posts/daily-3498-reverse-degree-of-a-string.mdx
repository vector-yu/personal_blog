## 方法：遍历

题目给出了字符在字符串中degree的定义 只需遍历字符串累加degree即可

## 代码

```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        return sum(((26 - (ord(c) - ord('a')))*(i+1) for i, c in enumerate(list(s))))
```

## 复杂度

- 时间复杂度：O(n), 我们遍历了列表一次
- 空间复杂度：O(1), 没有使用任何额外空间
