## 硬件

一台日常使用的笔记本，一块外接显示器，一把用了很久的键盘。没有太多讲究，顺手最重要。

## 编辑器与终端

- **编辑器**：VS Code，偶尔用 Cursor 做原型。
- **终端**：Windows Terminal + PowerShell / WSL。
- **版本控制**：Git + GitHub。

## 写作与设计

- **写作**：这个博客的编辑器本身就是 TinaCMS；草稿也会先写在本地 Markdown 里。
- **设计**：Figma 画布局和组件，Tailwind CSS 落地。
- **配色**：偏爱低饱和的纸张色，加一点高饱和的强调色。

## 这个站

Next.js App Router + TinaCMS + Tailwind CSS，部署在 Vercel。全站静态预渲染，内容可以在 `/admin/index.html` 里可视化编辑。
