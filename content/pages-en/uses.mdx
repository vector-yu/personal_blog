## Hardware

One everyday laptop, an external monitor, and a keyboard I have used for a long time. Nothing fancy; whatever feels natural matters most.

## Editor and terminal

- **Editor**: VS Code, occasionally Cursor for prototypes.
- **Terminal**: Windows Terminal + PowerShell / WSL.
- **Version control**: Git + GitHub.

## Writing and design

- **Writing**: The editor for this blog is TinaCMS itself; drafts also start as local Markdown.
- **Design**: Figma for layouts and components, Tailwind CSS for the implementation.
- **Palette**: mostly low-saturation paper tones, with a few saturated accents.

## This site

Next.js App Router + TinaCMS + Tailwind CSS, deployed on Vercel. The whole site is statically prerendered, and content can be edited visually at `/admin/index.html`.
